The theme for this section is an agent we'll develop for an e-commerce store that sells hardware such as headphones, keyboards, and laptops. The store runs promotions with bronze, silver, and gold discount tiers, each offering a different percentage discount.
We want to build a simple agent that takes a user's query and returns the discounted price of an item. It will use two tools:

- One tool retrieves an item's price, such as the price of a computer or laptop.
- The other retrieves the discount for the corresponding tier.
For example, the bronze tier offers a 15% discount. This is the concept we'll implement.
